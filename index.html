Recommended actions

    Buffers and batches

    Size WIP buffers against short stoppages, and check how changeovers eat into output.

    Method: assembly line balancing with task precedence and parallel stations. In "Meet demand" mode an operation longer than takt time runs on ⌈t ÷ takt⌉ parallel stations; shorter operations are grouped into shared stations that fit within takt, following the arrows. An exact search finds the fewest stations (up to 22 operations; larger lines use the ranked positional weight method), then cycle time is tightened as far as that many stations allow. In "Fixed workers" mode it searches for the shortest cycle time the given workers can reach. Throughput = 3600 ÷ cycle time (s). Line efficiency = work content ÷ (stations × cycle time), target 90%+. Idle time per station = cycle time − station time. Smoothness index = √Σ(cycle − station time)². WIP buffer = output per minute × stoppage minutes covered.
